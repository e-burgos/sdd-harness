# Nx 22 → 23

Fuente verificada: notas de release de Nx 23.0.0, https://github.com/nrwl/nx/releases/tag/23.0.0
Solo se listan cambios confirmados en esa página. Lo que no figura ahí no está verificado: leé
`migrations.json` y el changelog antes de asumir.

## Rompe o se elimina

- Node 20 deja de estar soportado: subí a una versión de Node que Nx 23 soporte antes de migrar.
- Las migraciones anteriores a v21 se eliminaron: un workspace más viejo que 21 no puede saltar directo.
- `'self'` y `'dependencies'` como strings mágicos en `dependsOn` se descartan (hoy avisan con warning);
  usá la forma de objeto (`{ "projects": "self" }`, `{ "dependencies": true }`).
- `nx watch --includeDependentProjects` pasa a llamarse `--includeDependencies`.
- `@nx/jest:jest` pierde la opción `setupFile` y `@nx/jest:configuration` pierde `skipSetupFile`.
- Se eliminó la opción `js` de los generadores de componentes y varias opciones de estilos deprecadas.
- Se eliminaron los generadores `setup-tailwind`.
- `@nx/vite` deja de soportar Vitest: usar `@nx/vitest`.
- `@nx/dotnet/plugin` se elimina: usar `@nx/dotnet` (una migración actualiza `nx.json`).
- `@nx/angular`: se eliminan `ngrx` (usar `ngrx-root-store` / `ngrx-feature-store`) y `move` (usar
  `@nx/workspace:move`); el entry `@nx/angular/module-federation` pasa a `@nx/module-federation/angular`
  (migración incluida).
- Se elimina el export deprecado `initTasksRunner` de `nx` (usar `runDiscreteTasks` o `runContinuousTasks`).
- Release: se descartan las propiedades planas `releaseTag*` y cambian los defaults de v23.
- Bundling: se elimina el plugin legacy de TypeScript, se alinea el default de `buildLibsFromSource`
  de Rollup y se elimina la opción SVGR (migración `withSvgr` incluida).
- Se eliminan reexports deprecados del plugin de webpack.

## Cambios de comportamiento

- El stripping nativo de TypeScript queda activado por defecto.
- `@nx/eslint`, `@nx/eslint-plugin`, `@nx/jest` y el resto de los plugins first-party pasaron a builds
  locales a `dist`.

## Deprecado (sigue andando, planificá el reemplazo)

- `withNx` de `@nx/next`, `nxViteTsPaths` y `nxCopyAssetsPlugin`, el executor `@nx/cypress:cypress`,
  los executors de `@nx/detox`, el soporte de ESLint v8, y los executors que tienen un plugin inferido
  equivalente.
